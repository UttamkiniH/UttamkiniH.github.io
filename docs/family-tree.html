A family tree, drawn from relationships

Tap a person, add relatives, switch to the list layout. This runs the app's own layout engines, ported line for line from Dart and checked against the app's tests.

My part

Since Oct 2026 · GeekyAnts

I lead Flutter development on a family tree app: the interactive tree, its layout engines and the add-relative seats, plus a photo and video feed.

Part 2 of How the engine works explains the app's backend code that turns links into words like Mother, which the tree depends on. This page runs the real engines, ported to JavaScript and checked against the app's tests: all 62 layout engine tests and all 65 kinship test cases pass.

How to use the tree

  1. Tap a person: their close family stays bright.
  2. Press and hold, right-click or press A to add a relative.
  3. Drag to move; pinch or use + and − to zoom.
The app's own colours; it has no dark mode.

Arrow keys move between people. Enter selects. A opens the seats for adding a relative. Plus and minus zoom, 0 recentres, Escape clears.
